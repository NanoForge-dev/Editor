## Online

Create a project from the [Project Dashboard](https://projects.nanoforge.eu/dashboard/projects). Click **New project** and fill in the project information.

![Create Project](../images/create-project.png)

To link the project to a GitHub repository, click **Add repositories from github** and select the organization to use.

Once the project is created, click **Open Editor**. The first time, a page asks for the programming language and whether the game is single-player or multiplayer.

![Init Project](../images/init-project.png)

## On your machine

With the NanoForge CLI:

```sh
nf new                   # asks for a name, a language, and whether the game has a server
nf editor my-game        # starts the editor and opens the project in your browser
```

`nf editor` without a path opens the list of recent projects. The first time a folder is opened, the editor asks whether you trust it. A trusted folder's code runs on your computer: its `nanoforge.config.ts`, its plugins, its builds and games, its Prettier and its Git hooks. **Open in restricted mode** keeps all of that off: you can read and edit the project, and **Trust this folder** (in the notification, or the command palette) turns it on later. Projects you create with **New project** are trusted. A local editor works on the folder itself: what you change in the editor is on your disk at once, and what you change on disk shows in the editor.

A local editor can do what a hosted one cannot: run the game, use Git with your own credentials, and install plugins and packages.

## The editor

![The editor](../images/editor-overview.png)

- **Top**: the menu bar, the four main **screens** (Project, Scene, Script, Game), and the **Play** button.
- **Left**: **Files**, the **Hierarchy** of entities and, for games made of scenes, **Scenes**.
- **Right**: the **Inspector**.
- **Bottom**: the **Console**.

The editor starts with these main panels only. _View › Layouts › All panels_ adds the others: **Commit**, **Components** and **Systems** on the left, **Problems**, **Git**, and the **Profiler**, **Network** and **World** panels at the bottom. _View › Panels_ opens any one of them, and the **History** of changes.

- **Status bar**: the project, the count of problems, the Git branch, and the game's speed while it plays.

Every panel can be moved, floated or closed: see [Layout](../editor/layout).
