## About

`@nanoforge-dev/editor-vite-plugin` is part of the NanoForge Editor.

Vite plugin to build editor plugins against the host's shared modules.

## Installation

**Node.js 26 or newer is required.**

```sh
npm install @nanoforge-dev/editor-vite-plugin
yarn add @nanoforge-dev/editor-vite-plugin
pnpm add @nanoforge-dev/editor-vite-plugin
bun add @nanoforge-dev/editor-vite-plugin
```
