## About

`@nanoforge-dev/editor-example-theme` is an internal package of the NanoForge Editor.

Example theme plugin: a color theme that extends the editor's dark one, an icon, and an icon theme, all from its manifest (no code). The theme guide of the plugin documentation walks through it; the end-to-end checks load it.
